About RentEase

RentEase is a static rental marketplace semester project that allows users to browse rental products across multiple categories, add products to a cart, and submit booking requests.

The website is built using HTML, CSS, and JavaScript. It uses browser localStorage for demo login, signup, cart, and booking data.

Objective

To create a simple, attractive and user-friendly rental platform where customers can find items on rent instead of purchasing them.

Technologies Used

  • HTML5 for page structure
  • CSS3 for responsive design and styling
  • JavaScript for interactivity
  • localStorage for demo data storage
  • GitHub Pages for free hosting
